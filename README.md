# Formatura TI116 — Vai Dar Praia 🌊

Projeto desenvolvido para fins **acadêmicos**, com o objetivo de praticar a utilização de **HTML semântico** na construção de uma página web.

A atividade simula uma página de informações e confirmação de presença para uma confraternização de formatura da turma **TI116 — Técnico em Informática**.

## 🎯 Objetivo

O principal objetivo do projeto foi aplicar corretamente a estrutura semântica do HTML, utilizando elementos que representam o significado e a função de cada parte do conteúdo, em vez de utilizar apenas elementos genéricos.

## 🧩 Estrutura semântica utilizada

Durante o desenvolvimento foram utilizados diversos elementos semânticos do HTML, entre eles:

* `<header>` — representa o cabeçalho da página, contendo o título e uma breve descrição do evento.
* `<main>` — concentra o conteúdo principal da página.
* `<section>` — organiza o conteúdo em diferentes seções, como informações do evento, localização, programação e confirmação de presença.
* `<h1>` e `<h2>` — utilizados para estabelecer uma hierarquia de títulos.
* `<p>` — utilizado para textos e descrições.
* `<dl>`, `<dt>` e `<dd>` — utilizados para organizar informações do evento em formato de lista de definição, como data, horário, local e confirmação.
* `<time>` — utilizado para representar datas de forma semanticamente adequada, incluindo o atributo `datetime`.
* `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>` e `<td>` — utilizados para representar a programação do evento de forma tabular.
* `<form>` — utilizado para estruturar o formulário de confirmação de presença.
* `<label>` e `<input>` — utilizados para criar e identificar os campos do formulário.
* `<fieldset>` e `<legend>` — utilizados para agrupar campos relacionados, como as opções de participação e os itens que cada pessoa levará.
* `<select>` e `<option>` — utilizados para a escolha do tamanho da camiseta.
* `<textarea>` — utilizado para observações e restrições alimentares.
* `<button>` — utilizado para o envio do formulário.
* `<iframe>` — utilizado para incorporar o mapa de localização do evento.
* `<footer>` — representa o rodapé da página.
* `<address>` — utilizado para apresentar as informações de contato da comissão de formatura.

## ♿ Acessibilidade

Além da utilização de elementos semânticos, foram aplicados alguns recursos para melhorar a acessibilidade e a usabilidade do formulário.

Os campos possuem associação entre `<label>` e `<input>` por meio dos atributos `for` e `id`. Também foram utilizados atributos como `required`, `minlength`, `maxlength`, `autocomplete` e `aria-describedby` para fornecer informações adicionais e auxiliar na validação e compreensão dos campos.

## 📚 Tecnologias

* HTML5
* CSS3

## 📝 Observação

Este projeto foi desenvolvido exclusivamente para **fins acadêmicos**, como exercício de estruturação de páginas utilizando HTML5 e seus elementos semânticos.

O foco principal da atividade está na **organização e semântica do HTML**, buscando utilizar cada elemento de acordo com sua finalidade e significado dentro da página.
